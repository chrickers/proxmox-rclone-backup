Privacy Policy

Last updated: 13 November 2026

Purpose

“Proxmox Backup” is a private, single-user setup of rclone. It is operated solely to back up the operator’s own Proxmox system to the operator’s own Google Drive. It is not offered to other users and has no other user accounts.

Google Drive access

rclone uses the Google Drive API. The currently documented configuration requests the OAuth scope drive, which can allow access to files in the authorizing Google Drive account. The backup jobs use the Proxmox-Backup destination, but this scope itself does not restrict access to that folder. The permission shown on Google’s consent screen is authoritative.

The setup accesses selected Proxmox backups and configuration archives, OAuth credentials needed for API requests, and local technical transfer and error logs. rclone runs on the Proxmox server; the operator does not run a separate application server for this backup tool.

Encryption, storage and retention

The backup jobs use rclone crypt to encrypt file contents and names before upload. The crypt configuration and passwords are kept separately from the backup files and must be protected by the operator. Encryption does not conceal all metadata, such as transfer timing and volume.

Google receives the API requests and stores the uploaded files encrypted by rclone crypt. The rclone OAuth credentials are stored locally on the Proxmox server. Google may process data under its own terms; see Google’s Privacy Policy.

Proxmox configuration archives are retained for 180 days. The retention of the remote PBS backup mirror follows the local PBS prune settings. Local log retention is not specified here. Deletions are applied by the relevant cleanup or synchronization job; items retained in Google Drive trash or version history may remain available according to Google’s settings.

Google API data use

Data received through Google APIs is used only to perform the backup and file-management operations initiated by the operator. It is not used for advertising or sold. The application’s use of Google user data is intended to comply with the Google API Services User Data Policy, including its Limited Use requirements.

This website

These static information pages are hosted by GitHub Pages. GitHub states that it logs and stores visitors’ IP addresses for security purposes. See GitHub’s Privacy Statement. This site does not use analytics or advertising services.

Revoking access

The operator can revoke the OAuth permission in the Google Account’s third-party connections settings. Revoking access does not automatically delete backups already stored in Google Drive.
